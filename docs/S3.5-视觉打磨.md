## 1. 选型原则（Codex 必须遵守）

1. **一个界面只有一个主特效**，其余都是微交互（≤ 200ms、不占注意力）
2. **优先纯 CSS / Canvas**，不用 JS 动画库
3. **禁止 `npm install framer-motion`** —— 它是 React 专用，装到 Vue 项目里是纯死重量
4. **特效服务于功能**：每个特效必须对应一个"用户动作"或"状态变化"，不做纯装饰
5. 新增特效后，**首屏帧率不得低于 50fps**（Chrome DevTools Performance 面板）

---

## 2. 选定的三处（只做这三个，不多不少）

### 2.1 登录页主按钮：**Star Border**（纯 CSS）

**位置**：`LoginView.vue` 的「进入 / 登录」按钮

**效果**：按钮边框有一道光沿边缘流动，像星光扫过。

**实现**（不依赖任何库）：

```css
.star-border {
  position: relative;
  isolation: isolate;
  border-radius: 10px;
  overflow: hidden;
}

.star-border::before {
  position: absolute;
  inset: -2px;
  z-index: -1;
  border-radius: inherit;
  background: conic-gradient(
    from var(--angle),
    transparent 0deg,
    rgba(124, 92, 255, 0.0) 60deg,
    rgba(124, 92, 255, 0.9) 90deg,
    rgba(255, 143, 177, 0.9) 120deg,
    transparent 180deg
  );
  content: '';
  animation: star-rotate 4s linear infinite;
}

@property --angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}

@keyframes star-rotate {
  to { --angle: 360deg; }
}
```

**兼容降级**：`@property` 不被支持时（旧 Safari），`--angle` 不会动，边框就是静态渐变——**可接受**，不要为此引入 polyfill。

**为什么选它**：登录页只有一个动作（进入），需要一个"值得点"的暗示。它比"按钮变亮"更有质感，且成本为零。

### 2.2 状态一标题：**Gradient Text 流动**（纯 CSS）

**位置**：`MoodInputStage.vue` 的「此刻，你的心情是怎样的？」

**效果**：文字本身是渐变，且渐变缓慢横向流动（不是发光呼吸）。

```css
.mood-title {
  background: linear-gradient(
    100deg,
    rgba(255, 255, 255, 0.92) 0%,
    rgba(180, 160, 255, 1) 30%,
    rgba(255, 160, 200, 1) 50%,
    rgba(180, 160, 255, 1) 70%,
    rgba(255, 255, 255, 0.92) 100%
  );
  background-size: 250% 100%;
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  animation: title-flow 9s ease-in-out infinite;
}

@keyframes title-flow {
  0%, 100% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
}
```

**注意**：

- 现有 `text-shadow` 与 `color: transparent` 冲突，**必须删掉旧的 text-shadow**，改用 `filter: drop-shadow()` 保留微光
- 周期 9 秒——**要慢**。快了会显得廉价
- `prefers-reduced-motion` 命中时停止动画

**为什么选它**：这句标题是整个产品的第一句话，也是唯一需要"被注视"的文字。流动 9 秒一次的渐变，比一直闪烁的光晕高级。

### 2.3 生成按钮点击：**Click Spark**（Canvas）

**位置**：`MoodInputStage.vue` 的「生成情绪胶囊」按钮

**效果**：点击瞬间，从点击位置向外放射 8 条短线，300ms 内淡出消失。

**实现**：一个独立组件 `ClickSpark.vue`，canvas 绝对定位覆盖按钮区域，`pointer-events: none`。

```js
// 关键参数
const SPARKS = 8          // 短线数量
const LIFE = 300          // 毫秒
const LEN = 14            // 基础长度
```

- 用 `requestAnimationFrame` 驱动
- 生命周期结束后**清空 canvas 并取消 rAF**，不要常驻动画循环
- 只在点击时创建一次，不需要监听全局

**为什么选它**：点"生成"之后有 1.8–3.2 秒的等待，**点击瞬间的反馈能填掉这段焦虑**。这是功能性特效，不是装饰。

## 3. 明确不做的（列出原因，避免 Codex 自由发挥）

| 不做的效果 | 原因 |
|---|---|
| 背景粒子/极光替代品 | 已有 `AuroraBackground`，重复且会打架 |
| 结果页任何新动效 | 已有音频频谱 + 雷达动画入场，再加会过载 |
| 光标特效（自定义光标、拖尾） | 干扰输入，且移动端无效 |
| 3D / WebGL（Three.js） | 体积 +50KB，与暗色扁平风格冲突 |
| 页面转场（复杂翻页/3D 翻转） | 已有 320ms 淡入，够了 |
| 音效（点击音） | 用户可能静音在看，且要与音乐播放器抢音频焦点 |

## 4. React → Vue 移植规则（关键）

ReactBits 的组件是 React 写的，**不能直接复制**。按类型处理：

| 组件类型 | 能否移植 | 方法 |
|---|---|---|
| 纯 CSS（Star Border、Gradient Text） | ✅ 直接抄 CSS | 无视框架 |
| Canvas + rAF（Click Spark） | ✅ 需要改写 | `useEffect` → `onMounted`，`useRef` → `ref()`，`useState` → `ref` |
| `framer-motion` 驱动（部分文字动画） | ❌ **不要移植** | 依赖 React，改用 CSS `@keyframes` 重写 |
| `three.js` / WebGL 背景 | ❌ 不引入 | 见 §3 |

**硬性要求**：

- 任何新增依赖前，先在报告里说明"为什么不能用 CSS 实现"
- 组件顶部注释写清：来源 URL + 移植时的改动点
- 保留原作者的 MIT 声明（在组件注释里写 `// Ported from reactbits.dev (MIT)`）

## 5. 性能预算

| 指标 | 上限 |
|---|---|
| 单个特效的 JS 体积 | ≤ 3KB（压缩后） |
| 常驻 rAF 循环 | **最多 2 个**（AuroraBackground 1 个 + 音频频谱 1 个） |
| Click Spark 之类短生命周期动画 | 允许临时创建，但必须销毁 |
| 首屏 JS 体积增量 | ≤ 5KB |

> 现有 `AuroraBackground` 已经占了一个常驻 rAF。**新品不能再加常驻循环**——这是最容易失控的地方。
