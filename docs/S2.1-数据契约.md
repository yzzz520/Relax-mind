## 决策记录

| 决定 | 选择 |
|---|---|
| 雷达图轴数 | **8 个**（超过 10 个视觉不可读） |
| "愤怒"是否上轴 | **否**，走词云（体现为 焦虑↑ + arousal↑） |
| 细粒度情绪（委屈/释然/怅然…） | 放 `fineLabels`，**不限数量** |
| 情绪坐标 | 用 `valence` / `arousal` 两个连续值，**由 8 维计算得出，不手写** |

**为什么是三层**：雷达图表达不了几十种情绪（人的视觉分辨率上限约 7±2）。所以"表达力"靠三个载体叠加，而不是靠加轴。

```
底层 valence / arousal   2 个连续值    → 音乐匹配用（Mood Quadrant）
中层 emotions            8 个固定轴    → 雷达图
表层 fineLabels          不限数量      → 词云
```

## 4. `keywords` 与 `fineLabels` 的区别（**不要合并**）

| 字段 | 内容 | 数量 | 显示位置 |
|---|---|---|---|
| `keywords` | 从用户原文提取的**实词**（面试、下雨、退堂鼓） | 3–5 | ① 解析动画第一句 ② 结果页疗愈语上方的"关于…"小字 |
| `fineLabels` | 情绪**形容词**（挫败、无力、被否定） | 5–8 | 结果页词云 |

两者用途完全不同，Codex 不要为了省事合并成一个数组。

## 5. `valence` / `arousal`：必须计算，不能手写

在 `mock.js` 里加一个导出函数：

```js
/**
 * 由八维情绪计算连续坐标。
 * valence  效价：-1（极度负面）~ 1（极度正面）
 * arousal  唤醒度：0（极度平静）~ 1（极度激动）
 * 权重是根据"该维度对情绪效价/唤醒度的贡献"人为设定的，可调。
 */
export function computeVAD(emotions) {
  const v =
    (emotions.喜悦 * 1.0 +
      emotions.期待 * 0.6 +
      emotions.平静 * 0.3 +
      emotions.温暖 * 0.7 -
      emotions.悲伤 * 1.0 -
      emotions.焦虑 * 0.7 -
      emotions.疲惫 * 0.5 -
      emotions.孤独 * 0.6) / 100

  const a =
    (emotions.焦虑 * 1.0 +
      emotions.喜悦 * 0.8 +
      emotions.期待 * 0.6 -
      emotions.疲惫 * 0.4 -
      emotions.平静 * 0.8 -
      emotions.温暖 * 0.3 -
      emotions.悲伤 * 0.3 -
      emotions.孤独 * 0.4) / 100

  return {
    valence: Math.max(-1, Math.min(1, Number(v.toFixed(2)))),
    arousal: Math.max(0, Math.min(1, Number(a.toFixed(2)))),
  }
}
```

**在 `analyzeMood` 返回前调用它**，把结果合并进 capsule：

```js
const capsule = { ...sample, ...computeVAD(sample.emotions) }
```

**禁止**在样本里手写 `valence` / `arousal` —— 否则数据和公式会不同步。
