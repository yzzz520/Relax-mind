## 0. 你（管理员）先要做的一件事

**管理员目前读不到别人的 `profiles`**——现有策略只允许读自己那行。

在 Supabase SQL Editor 执行：

```sql
-- 管理员可读所有 profiles（用于显示记录归属人昵称）
create policy "profiles_select_admin" on public.profiles
  for select using (
    coalesce((auth.jwt() -> 'app_metadata' ->> 'role'), '') = 'admin'
  );
```

**然后退出登录重新登录一次。**

> 原因：`app_metadata` 是在签发 JWT 时写进 token 的。你设置 role 之前拿到的 token 里没有它，
> 必须让 Supabase 重新签发一次，`isAdmin` 才会变成 `true`。

## 2. 数据获取（MVP 取舍：前端聚合）

**本期不做服务端聚合**（不写 SQL 函数、不建 view）。

原因：view 默认以所有者权限运行，**会绕过 RLS 变成数据泄露入口**；写 `security_invoker` 又增加复杂度。
当前数据量小，前端拉取后聚合更简单也更安全。

```js
// src/api/admin.js
const PAGE_LIMIT = 300

export async function fetchRecords({ quadrant = null, days = null } = {}) {
  let query = supabase
    .from('capsules')
    .select('id, created_at, input_text, emotions, valence, arousal, quadrant, profiles(nickname)')
    .order('created_at', { ascending: false })
    .limit(PAGE_LIMIT)

  if (quadrant) query = query.eq('quadrant', quadrant)
  if (days) {
    const since = new Date(Date.now() - days * 864e5).toISOString()
    query = query.gte('created_at', since)
  }

  const { data, error } = await query
  if (error) throw new Error(translateSupabaseError(error))
  return data ?? []
}
```

**注意 `profiles(nickname)`**：这依赖 §0 新增的策略。拿不到时 `profiles` 会是 `null`，
UI 要兜底显示「未知用户」，不能崩。

**口径必须写死，别自由发挥：**

| 指标 | 定义 |
|---|---|
| 总胶囊数 | 记录条数 |
| 今日生成 | `created_at` 落在**当天 00:00（+08:00）之后**的条数 |
| 平均效价 | 所有 `valence` 的算术平均，保留两位小数 |
| 最常见情绪 | 8 维中**平均值最高**的那个 |
| 八维均值 | 每维求平均，保留一位小数 |
| 最近 7 天 | 按 +08:00 的日期分组，无数据的日期补 0 |

> 时区必须用 `Asia/Shanghai`。直接 `new Date(created_at).getDate()` 会按浏览器时区算，
> 用户在别的时区看就会错一天。

## 4. 表格要求

- 列：时间（`MM-DD HH:mm`）· 用户 · 输入（超 24 字截断，`title` 放全文）· 主导情绪 · 效价 · 象限
- 象限用彩色标签：低落紫 / 紧绷青 / 明亮橙 / 平静蓝
- 效价按正负染色（负=冷色，正=暖色）
- 默认按时间倒序
- 移动端（<1024px）**允许横向滚动**，不要压缩列宽

## 5. 空状态 / 加载态 / 错误态

| 状态 | 表现 |
|---|---|
| 加载中 | 骨架屏或 `v-loading`，不要白屏 |
| 无数据（且不是筛选导致） | 标题「还没有情绪记录」+ 说明「用户生成胶囊后，这里会显示情绪分布与趋势」+ 按钮「去生成第一条」跳 `/` |
| 筛选后为空 | 「当前筛选条件下没有记录」+ 按钮「清除筛选」 |
| 请求失败 | 顶部一条错误提示 + 「重试」按钮，不要整页崩 |

> 空状态是对外展示的细节，**不要用「暂无数据」四个字敷衍**。
