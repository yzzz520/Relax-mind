## 4. 雷达图 `EmotionRadar.vue`

### 契约

```js
props: {
  emotions: { type: Object, required: true },  // 8 键，0-100
  palette:  { type: Array, default: () => ['#7C5CFF', '#FF8FB1'] },
}
```

### ECharts 配置要点

```js
const option = {
  radar: {
    indicator: EMOTION_DIMENSIONS.map((name) => ({ name, max: 100 })),
    center: ['50%', '54%'],
    radius: '62%',
    splitNumber: 4,
    axisName: {
      color: 'rgba(255,255,255,0.6)',
      fontSize: 12,
      padding: [3, 5],
    },
    splitLine: { lineStyle: { color: 'rgba(255,255,255,0.12)' } },
    splitArea: {
      areaStyle: {
        color: ['rgba(255,255,255,0.03)', 'rgba(255,255,255,0.06)'],
      },
    },
    axisLine: { lineStyle: { color: 'rgba(255,255,255,0.10)' } },
  },
  series: [
    {
      type: 'radar',
      data: [
        {
          value: EMOTION_DIMENSIONS.map((d) => emotions[d] ?? 0),
          symbol: 'circle',
          symbolSize: 5,
          lineStyle: { width: 2, color: palette[0] },
          itemStyle: { color: palette[0] },
          areaStyle: {
            color: {
              type: 'radial',
              x: 0.5, y: 0.5, r: 0.75,
              colorStops: [
                { offset: 0, color: hexToRgba(palette[0], 0.10) },
                { offset: 1, color: hexToRgba(palette[0], 0.45) },
              ],
            },
          },
        },
      ],
    },
  ],
  animationDuration: 900,
  animationEasing: 'cubicOut',
}
```

> `hexToRgba(hex, alpha)` 自己写一个 5 行工具函数，放在组件内部或 `src/utils/color.js`。

### 必须避开的 5 个坑

| 坑 | 后果 | 解法 |
|---|---|---|
| 容器高度为 0 时初始化 | 图表空白且不报错 | 容器必须有明确高度（如 `height: 320px`），并 `ResizeObserver` + `chart.resize()` |
| 组件卸载不 dispose | 内存泄漏、重复实例警告 | `onBeforeUnmount(() => chart?.dispose())` |
| 数据变化时重新 init | 图表闪烁、旧实例残留 | `watch(..., () => chart.setOption(option, true))` |
| 8 轴标签被裁切 | 顶部/底部标签看不见 | `radius: '62%'` 且 `center[1]` 略下移，容器 `padding: 8px 0` |
| `value` 顺序与 `indicator` 不一致 | 图形完全错位 | 两个数组都由 `EMOTION_DIMENSIONS` 生成，不要手写顺序 |

**数值顺序必须和 `EMOTION_DIMENSIONS` 同源**，禁止手写数组。

## 5. 标签云 `KeywordCloud.vue`

### 决策：**手写标签云，不用 `echarts-wordcloud`**

理由三条：

1. 你的参考设计里是**整齐排布的标签**，不是随机布局的词云——手写更接近目标效果
2. `echarts-wordcloud` 对 ECharts 5.x 版本敏感，容易白屏，排查成本高
3. 少一个依赖，样式能和玻璃拟态完全统一

`package.json` 里的 `echarts-wordcloud` 保持不动（不必卸载），但本组件不引入。

### 契约

```js
props: {
  labels: { type: Array, required: true },   // fineLabels，5-8 个
}
```

### 实现

```vue
<div class="tag-cloud">
  <span
    v-for="(label, i) in labels"
    :key="label"
    class="tag"
    :style="tagStyle(i)"
  >{{ label }}</span>
</div>
```

```css
.tag-cloud {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
  align-content: flex-start;
}
.tag {
  padding: 6px 14px;
  border-radius: 999px;
  border: 1px solid rgba(255, 255, 255, 0.14);
  background: rgba(255, 255, 255, 0.05);
  color: rgba(255, 255, 255, 0.88);
  transition: transform 200ms, background 200ms;
  cursor: default;
}
.tag:hover {
  transform: translateY(-2px) scale(1.04);
  background: rgba(255, 255, 255, 0.12);
}
```

**字号递减**：第 1 个 18px，之后按顺序递减到 13px：

```js
function tagStyle(i) {
  const size = Math.max(13, 18 - i * 1.2)
  return {
    fontSize: `${size}px`,
    transform: `rotate(${((i % 3) - 1) * 1.2}deg)`,  // -1.2° / 0° / 1.2°
  }
}
```

**入场动画**：逐个淡入，`animation-delay: i * 60ms`。

## 7. 背景联动

给 `AuroraBackground.vue` 加：

```js
colors: { type: Array, default: () => ['#7C5CFF', '#FF8FB1'] }
```

两个光斑 `div` 的 `background-image` 用这两个颜色生成径向渐变，**颜色变化要过渡**（`transition: background-image 800ms` 对渐变不生效，改用两个独立层各自 `transition: opacity`，或用 CSS 变量 + `background: radial-gradient(...)` 配合 300ms 的 `--p1`/`--p2` 过渡——**若实现困难，允许直接切换颜色，不做过渡**，但要在报告里说明）。

`CapsuleView` 里：

```vue
<AuroraBackground
  :intensity="stage === 'analyzing' ? 1 : stage === 'result' ? 0.6 : 0.3"
  :colors="capsule?.palette ?? undefined"
/>
```

## 9. 状态机接入

`ResultStage.vue`：

```js
props: { capsule: Object }
emits: ['restart']

function onRestart() { emit('restart') }   // 父组件调用 flow.reset()
```

`CapsuleView.vue` 用 `<ResultStage v-else :capsule="capsule" @restart="flow.reset" />` 替换原来的占位 `div`。

**注意**：`capsule` 在 `result` 态一定有值，但模板里仍要写成 `v-if="capsule"` 的防御式，避免报错。
