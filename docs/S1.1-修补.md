## 1. 退出入口（两个页面都要）

**文件**：`src/views/CapsuleView.vue`、`src/views/AdminView.vue`

在两个页面 `<header>` 的右侧各加一个"退出"按钮。

**样式**：

- 文字按钮，`opacity: 0.55`，`:hover { opacity: 1 }`
- 不要做成实心大按钮，不要抢视觉
- 与 header 内其他元素垂直居中对齐

**逻辑**：

```js
import { useRouter } from 'vue-router'

const router = useRouter()

function handleLogout() {
  auth.logout()
  router.replace('/login')   // 必须用 replace，不能用 push
}
```

> 为什么用 `replace`：用 `push` 的话，浏览器历史里会留下已登录页面，用户按返回键会跳回去，出现"退出后还能退回登录态"的诡异现象。

## 2. 路由守卫去掉特判

**文件**：`src/router/index.js`

**删除**：

- `to.query.from !== 'admin'` 这个条件
- 配套的 `query: { from: 'admin' }` 传参

**改为**：

- 已登录用户访问 `/login` 时，一律按角色跳转：`admin → /admin`，`user → /`
- `requiresAdmin` 分支里直接 `return { name: 'login' }`，不再带 query

**目标形态**（参考，不必逐字照抄）：

```js
router.beforeEach((to) => {
  const auth = useAuthStore()

  if (to.meta.guestOnly && auth.isAuthenticated) {
    return auth.isAdmin ? { name: 'admin' } : { name: 'capsule' }
  }

  if (to.meta.requiresAuth && !auth.isAuthenticated) {
    return { name: 'login' }
  }

  if (to.meta.requiresAdmin && !auth.isAdmin) {
    return { name: 'login' }
  }

  return true
})
```

## 3. 登录延迟

**文件**：`src/api/auth.js`

`login()` 和 `adminLogin()` 里的 `sleep`，从 `random(1800, 3200)` 改为 `random(400, 800)`。

> 原因：1800–3200ms 是情绪解析的延迟，不是登录该有的。登录等 3 秒用户会以为卡死。
