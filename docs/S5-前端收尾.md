## 批次 1：空状态 + 多源回退（30 分钟）

### 1.1 空状态设计

借鉴 Folia 的做法：**没有数据时，不只说"没有"，要告诉用户"为什么"和"怎么办"。**

改三个地方：

| 位置 | 现在 | 改成 |
|---|---|---|
| `AdminView` 无记录时 | 空表格 | 标题「还没有情绪记录」+ 说明「用户生成胶囊后，这里会显示情绪分布与趋势」+ 按钮「去生成第一条」 |
| 结果页无音频时 | 按钮置灰 | 文案「这首歌暂时无法试听」+ 链接「去网易云听」 |
| 曲库某象限为空 | 返回 null | 自动回退到相邻象限（见 1.2） |

文案样式：标题 16px / 55% 透明，说明 13px / 40% 透明，居中对齐，最大宽度 420px。

### 1.2 三级回退（永不走进死胡同）

`pickMusic` 改成三级回退：

```
① 本象限有曲目 → 用
② 本象限为空 → 按「情绪相近度」找相邻象限
   映射：melancholic ↔ anxious（同为负面）、calm ↔ joyful（同为正面）
③ 全部为空 → 返回 null，UI 显示"曲库为空"空状态
```

**注意**：本批曲库每象限 1 首，回退逻辑要写，但你是测不出来的。**在 `pickMusic` 里加注释说明"当前数据下回退分支不可达，属预留"**，不要为了测试去造假数据。

### 1.3 验收

- [ ] 管理后台无数据时，显示三段式空状态（标题/说明/按钮），不是空白表格
- [ ] 点空状态里的按钮，能跳到 `/`（生成页）
- [ ] 全局搜索 `还没有`，至少 2 处
- [ ] `pickMusic` 有三级回退注释和实现，`npm run build` 通过

### 2.2 数据来源（关键）

**现在没有后端，用 `mock.js` 里的样本 + 本地生成的历史记录凑数。**

在 `src/api/admin.js` 里提供：

```js
// 第一版：从 localStorage 读真实产生过的胶囊 + mock 样本补足到 20 条
export async function fetchRecords() -> Promise<Record[]>
export async function fetchStats()  -> Promise<Stats>
```

**真实来源**：`useEmotionFlow` 每次生成成功时，往 `localStorage` 的 `capsule_history` 追加一条（只存必要字段，不存音频）。

这样后台看到的是**用户真的生成过的数据**，比全假数据有说服力得多。

**追加时机**：`analyzeMood` 成功后，在 `useEmotionFlow` 里写。最多保留 50 条（超出丢弃最旧）。

## 批次 3：导出情绪卡片（2 小时）

### 3.1 触发

结果页底部按钮「保存为情绪卡片」。

### 3.2 必须处理的坑（这个组件的主要工作量）

`html2canvas` **不支持 `backdrop-filter`**，而你的卡片全是玻璃拟态。直接导出会得到半透明甚至黑块。

**标准解法**：导出前给 `body` 加 `.exporting` 类，把玻璃元素换成不透明背景：

```css
.exporting .glass,
.exporting .result-card {
  backdrop-filter: none !important;
  background: rgba(30, 28, 50, 0.94) !important;
}
.exporting canvas {
  /* WebGL canvas 在导出时可能抓不到，用 CSS 兜底背景 */
  display: none !important;
}
```

**同时**：导出时隐藏 WebGL 组件（Lightfall / Radar / Particles），用一个静态渐变替代——WebGL 内容 `html2canvas` 100% 抓不到，会变黑块。

### 3.3 导出内容

只截「左栏播放器卡片 + 右栏雷达卡片 + 疗愈语」，**不包括**顶部 header 和底部按钮。

```js
const canvas = await html2canvas(el, {
  backgroundColor: '#0B0A14',
  scale: 2,
  useCORS: true,
  logging: false,
})
```

文件名：`情绪胶囊-${YYYY-MM-DD-HHmm}.png`

### 3.4 细节

- 导出中按钮显示"正在生成…"，禁用
- 成功后恢复，并用 toast 提示"已保存"
- 失败时提示具体原因，不要静默失败
- **`document.body.classList.remove('exporting')` 必须放在 `finally` 里**，否则导出失败会永久污染页面样式

### 3.5 验收

- [ ] 点导出，1–3 秒内下载一张 PNG
- [ ] 图片里**没有黑块**（WebGL 区域已被静态背景替代）
- [ ] 图片里文字清晰，雷达图可见
- [ ] 连续导出 3 次，页面样式恢复正常（没有残留的 `.exporting` 效果）
- [ ] 导出期间页面不闪烁
- [ ] `npm run build` 通过
