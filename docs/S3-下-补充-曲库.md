## 1. 为什么要改：现在的写法不是"推荐"

原规格里，音乐是写死在每个样本上的：

```js
// ❌ 现在 mock.js 里的样子
{ emotions: {...}, music: { title: '雨夜的退堂鼓', audioUrl: '/audio/x.mp3' } }
```

这等于"4 个样本配 4 首歌"，是**硬编码**，不是推荐。

改成"曲库 + 按象限选曲"之后，代码里才真的发生"根据情绪挑歌"这件事。

## 3. 新增文件 `src/utils/pickMusic.js`

```js
import { MUSIC_LIBRARY } from '../data/musicLibrary'

/**
 * 由效价/唤醒度判断象限。
 * 阈值 0.5 是唤醒度的中点，可按体验调整。
 */
export function quadrantOf(valence, arousal) {
  if (valence < 0 && arousal < 0.5) return 'melancholic'
  if (valence < 0) return 'anxious'
  if (arousal < 0.5) return 'calm'
  return 'joyful'
}

/**
 * 稳定哈希：同一个 seed 永远得到同一首，
 * 避免"刷新页面就换歌"的困惑。
 */
function hashString(s) {
  let h = 0
  for (let i = 0; i < s.length; i += 1) {
    h = (h * 31 + s.charCodeAt(i)) >>> 0
  }
  return h
}

/**
 * 按情绪挑歌。
 * @param {number} valence -1 ~ 1
 * @param {number} arousal 0 ~ 1
 * @param {string} seed    必须是**用户输入文本**（text），保证同一段话永远选同一首。
 *                        禁止用 capsuleId —— 它是 Date.now() + 随机数，每次生成都不同，
 *                        会让"稳定"完全失效（同一段文本连点三次会换三首歌）。
 */
export function pickMusic(valence, arousal, seed = '') {
  const quadrant = quadrantOf(valence, arousal)
  const list = MUSIC_LIBRARY[quadrant]

  if (!list || list.length === 0) {
    return null
  }

  const index = hashString(String(seed)) % list.length
  return { ...list[index], quadrant }
}
```

## 4. 改造 `mock.js`

### 4.1 删除样本里的 `music` 字段

四个样本里的 `music: {...}` **整块删掉**。音乐不再由样本决定。

### 4.2 `analyzeMood` 里动态选曲

```js
import { pickMusic } from '../utils/pickMusic'

// 在 analyzeMood 中，算完 VAD 之后：
const vad = computeVAD(sample.emotions)
const capsuleId = `cap_${Date.now()}_${Math.random().toString(16).slice(2, 6)}`

const capsule = {
  ...sample,
  capsuleId,
  ...vad,
  // seed 用原始输入文本，不用 capsuleId：
  // 同一段话 → 永远同一首；不同的话（即使同象限）→ 可能不同首。
  music: pickMusic(vad.valence, vad.arousal, inputText),
}
```

> ⚠️ **这里是最容易写错的地方。** 用 `capsuleId` 当 seed 会得到一个"看起来有哈希、实际每次都变"的假稳定。
> `capsuleId` 仍然要生成（它是胶囊的唯一标识，S4 存数据库要用），但**不参与选曲**。
> `inputText` 是 `analyzeMood(text)` 的入参，直接用。

### 4.3 新增第 5 个样本（覆盖 calm 象限）

现在四个样本的象限是：1→melancholic、2→joyful、3→melancholic、4→anxious。
**calm 永远用不到**，`calm-1.mp3` 播不出来。

加一个：

| 项 | 值 |
|---|---|
| 触发词 | 阳光 / 晒 / 舒服 / 安静 / 慢慢 |
| emotions | 喜悦 40，期待 30，平静 82，温暖 75，悲伤 0，焦虑 5，疲惫 10，孤独 5 |
| keywords | 阳光、被子、安静、暖 |
| fineLabels | 松弛、满足、安心、慢下来、踏实 |
| comment | 「挺好的，这样安静的一刻值得被记住。让这段旋律陪你把这份松弛多留一会儿。」 |

按 `computeVAD` 计算应得到 valence ≈ 0.84、arousal ≈ 0.37 → **calm** 象限。

## 8. 附录：每象限只有 1 首时，怎么验证稳定哈希

**问题**：`hash % 1` 恒等于 0。每象限只有 1 首时，稳定哈希永远返回第 0 个，
"同一段文本选同一首"是自动成立的，**测不出来任何东西**。

### 方案：临时复制"记录"，不复制"文件"

**不要**为了测试去下载更多歌，也**不要**真的复制 mp3 文件（浪费 3MB×N）。

只在 `musicLibrary.js` 的 `calm` 分组里临时刻两条指向同一文件的记录：

```js
calm: [
  { id: 'calm-1', title: 'calm-1', artist: '待确认', file: '/audio/calm-1.mp3', license: 'PLACEHOLDER', source: null },
  // ⚠️ 以下两条仅用于验证哈希分布，验证完删除
  { id: 'calm-2', title: 'calm-1', artist: '待确认', file: '/audio/calm-1.mp3', license: 'PLACEHOLDER', source: null },
  { id: 'calm-3', title: 'calm-1', artist: '待确认', file: '/audio/calm-1.mp3', license: 'PLACEHOLDER', source: null },
],
```

**零字节成本**，代码逻辑完全不变，只是让 `list.length` 从 1 变成 3，哈希才有分布空间。

### 验证脚本

新增 `scripts/test-pick-music.mjs`（**只用于验证，不参与构建**）：

```js
// 用法：node scripts/test-pick-music.mjs
import { pickMusic, quadrantOf } from '../src/utils/pickMusic.js'

const SAME = '今天面试被挂了，外面还在下雨，感觉好累'

// ① 稳定性：同一段文本 100 次
const ids = new Set()
for (let i = 0; i < 100; i += 1) {
  ids.add(pickMusic(-0.76, 0.44, SAME).id)
}
console.log('① 同一文本 100 次 →', [...ids], ids.size === 1 ? 'PASS' : 'FAIL')

// ② 分布：10 段不同文本，同一象限
const texts = [
  '今天好累啊', '面试又挂了', '一个人待着', '外面下雨了',
  '什么都不想做', '感觉自己很没用', '不想说话', '有点想哭',
  '压得喘不过气', '今天真的撑不住了',
]
const tally = {}
for (const t of texts) {
  const m = pickMusic(-0.7, 0.3, t)
  tally[m.id] = (tally[m.id] || 0) + 1
}
console.log('② 10 段文本分布 →', tally)
console.log('   不同 id 数 =', Object.keys(tally).length, Object.keys(tally).length >= 2 ? 'PASS' : 'FAIL')

// ③ 象限判定抽查
for (const [v, a, want] of [[-0.7, 0.3, 'melancholic'], [-0.7, 0.7, 'anxious'], [0.8, 0.7, 'joyful'], [0.8, 0.3, 'calm']]) {
  const got = quadrantOf(v, a)
  console.log(`③ (${v}, ${a}) → ${got}`, got === want ? 'PASS' : `FAIL(期望 ${want})`)
}
```
